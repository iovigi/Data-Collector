# Data Collector 2.0 — Web Admin Dashboard

Next.js App Router + TypeScript + Tailwind CSS + TanStack Query/Table admin console backed by a same-origin BFF (`/api/auth/*`, `/api/backend/*`).

## Local Development
```bash
cd web
cp .env.example .env.local
npm ci
npm run dev
```

## Verification
```bash
npm run lint
npm run typecheck
npm run test
npm run build
```
